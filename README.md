# Cinema Service

Сервис управления кинотеатром.

## Описание

Приложение предоставляет консольный интерфейс для управления кинотеатром. После запуска отображается главное меню:

```
=== Система управления кинотеатром ===
[1] Залы
[2] Фильмы и жанры
[3] Сеансы
[4] Пользователи
[5] Билеты
[6] Отчёты и аналитика
[7] Многопоточные операции
[8] Демонстрация
[0] Выход
```

## Функциональность

**Основные сущности:** залы, фильмы, жанры, сеансы, пользователи. Для каждой сущности доступны операции просмотра, добавления, поиска и удаления. При создании сеанса автоматически генерируются билеты на каждое место зала.

**Билеты:** просмотр свободных мест сеанса, покупка билета, просмотр билетов пользователя с указанием времени продажи.

**Отчёты:** выручка по сеансу, популярность фильмов, общая статистика системы.

**Многопоточные операции:** имитация работы нескольких кассиров (потоки `Cashier-1…N`), которые параллельно обрабатывают очередь заявок на покупку билетов. Имя потока выводится в журнал событий.

**Демонстрация:** автоматический сценарий, демонстрирующий все возможности системы (добавление данных, вывод информации, поиск, покупка билетов, удаление, многопоточная обработка, формирование отчётов).

**Защита данных:** запрещено удаление зала или фильма, если существуют связанные сеансы; сеанса с проданными билетами; пользователя с приобретёнными билетами.

**Роли пользователей:** абстрактный класс `User` и его наследники `AdminUser`, `ManagerUser`, `CustomerUser`.

## Структура проекта

| Пакет | Назначение |
|---|---|
| `com.cinema.model` | Классы предметной области: `Hall`, `Genre`, `Film`, `FilmSession`, `Ticket`, `User` и его наследники; перечисления `TicketStatus`, `UserRole` |
| `com.cinema.repository` | Интерфейс хранилища `EntityRepository`, реализация в памяти `InMemoryRepository`, конфигурация `RepositoryConfig` |
| `com.cinema.service` | Интерфейсы и их реализации для работы с залами, жанрами, фильмами, сеансами, билетами, пользователями и отчётами |
| `com.cinema.concurrent` | Многопоточная обработка: `NamedThreadFactory`, `PurchaseRequest`, `PurchaseProcessor`, `ParallelPurchaseProcessor` |
| `com.cinema.cli` | `ConsoleApp` (главное меню), `ConsoleIO` (ввод данных), `TablePrinter` и `EntityPrinter` (форматированный вывод таблиц), `DemoRunner` (демонстрационный сценарий) |

## Используемые коллекции

- `Map` (`ConcurrentSkipListMap`) — хранение сущностей по уникальному ключу;
- `Set` (`CopyOnWriteArraySet`) — хранение жанров фильма без дубликатов;
- `Queue` (`ConcurrentLinkedQueue`) — очередь заявок на покупку билетов;
- `List` (`ArrayList`) — результаты поисковых запросов.

## Многопоточная обработка

Класс `ParallelPurchaseProcessor` создаёт пул потоков с именами `Cashier-N` (используя `ExecutorService` и `NamedThreadFactory`). Каждый кассир извлекает заявки из общей очереди. При наличии нескольких заявок на один билет успешно обрабатывается только первая.
